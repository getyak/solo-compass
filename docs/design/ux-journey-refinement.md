# 常用旅行流程优化 · 2026-09-21

基线：`554040235cd281c7c9c92f38d4d002849597c459`。实现位于 `codex/ux-journey-refinement`，不覆盖原工作区的未提交内容。

## 产品边界

保留 2026-09-20 已批准的连续对话工作区：地图 / 问问 / 发现共用状态，默认仍为问问。此次先完成不依赖新产品决策的优化。首页默认意图、收藏/行程是否变为独立底栏、次要旅行功能的展示层级，已向用户提出选择，尚未收到答复。

## 实现

- 问问空态用完整问题展示可执行的意图，扩大点击区域，取消过小的英文大写时间标签。保留原有消息、输入草稿、语音生命周期和地图上下文。
- 发现页提供全局收藏与行程入口；先展示体验，将基地信息后置。搜索始终可用，中文分类参与匹配；在线搜索区分失败、无结果和已找到，旧城市的响应不写入新城市。
- 体验卡减少装饰并移除用英文字符串猜测“安静、英文标识”等事实的标签。原始体验内容和来源保持可追溯，尚未完成整个内容库的翻译。
- 详情主操作改为加入行程，收藏、问问、去过补文字；不把跨洲距离放在主要决策信息中。
- 加入行程使用一个导航容器：继承体验城市、预填可编辑标题和日期，保存时一次写入体验 ID。取消不写入任何行程；保存失败不触发成功回调；编辑保留原值。
- 档案移除内部 Tool Router / Live Activity / manifest 预览入口，实际旅行功能使用本地化名称。
- 路线工具返回实际站点及顺序，拒绝悄悄替换无法找到的指定站点。模型仍可能违反说明，不能把这一修复当成“所有自然语言约束已验证”；真实 coffee + sunset 用例已经复测：回复逐站对应实际 3 站，明确承认缺少落日站点。完整意图满足仍未关闭。
